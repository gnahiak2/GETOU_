# GETOU_ — 3×4 RP2040 Macropad

A custom programmable 12-key macropad powered by **QMK firmware** and built around the RP2040 microcontroller.

---

## 🧠 What is this project?

GETOU_ is a compact, fully programmable macropad designed to give you fast access to shortcuts, macros, and workflows in a tiny 3×4 layout.

It turns a simple grid of 12 keys into a powerful control surface for:
- productivity shortcuts (copy, paste, window switching)
- media controls (play, pause, volume)
- coding workflows (snippets, commands)
- gaming or custom macros

---

## 💡 Why I made this

I wanted a macropad that was:

- **small but powerful**
- fully customizable with QMK
- easy to build using RP2040 boards
- flexible enough to become anything (numpad, stream deck, shortcut pad)

Most macropads are either expensive or locked behind proprietary software — this one is fully open and programmable.

---

## ⌨️ How it works

GETOU_ uses:

- 🧠 **QMK firmware** for key programming
- ⚡ **RP2040 microcontroller** (XIAO RP2040 recommended)
- 🔌 3×4 switch matrix (12 keys total)
- 📦 JSON-based keyboard definition

---

## 🧩 Features

- 12-key 3×4 layout
- Fully programmable keymaps
- NKRO support (multiple keys at once)
- Lightweight QMK config
- RP2040 compatible
- Easy flashing via UF2
